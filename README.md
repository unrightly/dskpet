# 绒绒桌宠 · DskPet

一个常驻 Windows 桌面的小宠物：透明置顶、会自己换表情、按时间冒气泡碎碎念；左键点她打开大对话框，可接入任意 OpenAI 兼容大模型，带长期记忆，能收文件，回复里的链接和本地文件路径都能直接点开。

基于 Electron + 原生 HTML/CSS/JS，除 Electron 外没有运行时依赖。

---

## 功能对照

| 需求 | 实现 |
|---|---|
| 常驻桌面、不被其他应用覆盖 | 无边框透明窗 + `screen-saver` 级置顶，每 4 秒重新断言置顶；不占任务栏；宠物以外的透明区域鼠标穿透，不挡下面的窗口 |
| 未交互时多种表情/状态 | 8 种表情（普通、开心、好奇、困倦、爱心、思考、说话、眨眼）+ 呼吸、眨眼、耳朵抖、尾巴摇、跳跃、伸懒腰、打哈欠、星星闪烁；按时间与交互自动切换 |
| 定时气泡提醒 | 默认每 10 分钟（1–240 可调）在头顶冒出气泡；按清晨/上午/午间/下午/傍晚/夜晚/深夜七套台词库选句，可选让模型生成“碎碎念” |
| 左键点击进入对话 | 大对话窗：流式回复、会话列表、Markdown、代码块复制、停止生成、记忆抽屉 |
| 自定义 system / person / soul | 设置 → 人格：名字、主题色、介绍、开场白、`persona`（人设）、`soul`（灵魂/价值观）、`style`（说话方式）、专属气泡台词；内置 3 个预设，可新建/复制/删除/切换 |
| API 接入大模型 | 任意 OpenAI 兼容 `/chat/completions`；内置 OpenAI / DeepSeek / Moonshot / 智谱 / 通义 / 硅基流动 / Ollama / LM Studio 预设；支持自定义 Base URL、模型、温度、max_tokens、视觉输入、额外请求头 |
| 每次对话整理记忆、新对话不从零开始 | 每约 2 轮自动让模型整理：更新「长期档案」并写入一条「片段」；新对话的 system 会自动带上档案 + 最近 8 条片段 + 当前时间 |
| 回复里的 URL / 文件可点击打开 | 外链用默认浏览器打开；`C:\...`、UNC 路径用关联程序打开（Alt+点击在资源管理器中定位）；附件芯片同样可点开 |
| 对话时发送文件 | 📎 选择或直接拖入窗口；≤2MB 文本会内联进消息，≤5MB 图片在开启视觉时直接给模型看，其余文件提供路径 |
| 界面观感 | 对话/设置窗使用透明圆角窗 + 柔和投影；窗口、卡片、气泡、按钮统一 `corner-shape: squircle` 连续曲率圆角（Chromium 140 原生支持） |
| 长回复与代码 | 命中 `max_tokens` 时自动续写（最多 3 段），避免半截代码；超过 12 行的代码块默认收起，可展开/收起、复制 |

## 快速开始

要求：Windows 10/11，Node.js 18+（开发时用 Node 24 验证）。

```bash
cd E:\dskPet
npm install
npm start
```

也可以双击 **`启动桌宠.bat`**（首次会自动安装依赖）。如果应用已经在后台运行，再次双击不会开第二个实例，而是把宠物和对话窗一起唤到前台。

首次启动后：

1. 托盘出现小猫图标，右下角出现宠物。
2. 左键点宠物 → 打开对话窗。
3. 右上角 ⚙ →「模型」，选择服务商预设，填 API Key / 模型名，点「测试」。
4. 保存后即可聊天。

不配置模型也能用：宠物动画、定时气泡、人格切换、记忆查看都正常；聊天会给出配置提示。

### 本地模型（无需 Key）

```bash
ollama pull qwen2.5:7b
```

设置 → 模型 → 服务商选「Ollama 本地」，Base URL `http://127.0.0.1:11434/v1`，模型 `qwen2.5:7b`，Key 留空。

## 使用说明

- **拖动**：按住宠物拖动换位置，位置会记住。
- **左键**：打开对话；**右键**：快捷菜单（说话 / 隐藏 / 设置 / 退出）。
- **气泡**：点击气泡也能打开对话；托盘菜单「让她说句话」可立即来一句。
- **穿透**：鼠标不在宠物/气泡上时，窗口透明区域不会拦截下面应用的点击。
- **附件**：对话窗里点 📎，或把文件拖进窗口；发送前可点 ✕ 移除。
- **链接/文件**：回复中的 `https://...`、`C:\...` 直接点击打开；按住 Alt 点击文件路径可在资源管理器中定位。
- **停止**：生成中点 ■ 可中断，已生成的部分会保留。
- **新对话**：每次从宠物/托盘打开对话都会新建一段草稿；发出第一条消息才会保存，没发消息就关闭不会留下空会话。左侧列表只显示真正聊过的会话，可切换/删除，仍会携带长期记忆。
- **长代码**：超过 12 行的代码块默认收起，点「展开」查看，点「收起」再折起来；模型输出被 `max_tokens` 截断时会自动带着上下文续写。
- **记忆抽屉**：对话窗 🧠 可查看长期档案和最近片段，也能「现在整理一次」。

## 人格与 system 提示

每个预设包含四层：

- `persona`：她是谁、如何理解自己；
- `soul`：价值观、在意的东西、情绪边界；
- `style`：句子长短、语气、称呼习惯；
- 专属气泡台词：补充她自己的碎碎念。

实际发给模型的 system 由以下内容拼成（见 `src/memory.js`）：

```
人格 + 灵魂 + 表达方式
+ 长期档案（profile）
+ 最近 8 条记忆片段
+ 当前日期 / 时间 / 时段氛围
+ 输出与安全规则（Markdown、完整路径、别编造）
```

修改人格后，宠物名字、主题色、开场白和对话里的身份会一起变化。

## 记忆是怎么工作的

1. 每约 2 轮对话（累计 4 条消息）后，后台调用一次模型做「记忆整理」。
2. 模型返回严格 JSON：`profile`（长期档案）、`episode`（本次片段）、`tags`、`mood`。
3. `profile` 合并旧档案后覆盖保存；`episode` 追加到片段列表（默认最多 120 条，可在 `src/defaults.js` 调整）。
4. 新对话时，system 自动注入档案 + 最近 8 条片段。
5. 关闭对话窗或新开对话时，会顺手把剩余未整理的内容补一次，避免漏记。
6. 也可以手动「现在整理一次」；档案可手动编辑；「清空记忆」会重置档案并把历史会话标记为已整理，避免旧内容立刻被重新喂回来。

整理失败不会影响聊天，也不会破坏旧记忆。

## 数据与隐私

全部保存在本机 `%APPDATA%\DskPet\data\`：

| 文件 | 内容 |
|---|---|
| `config.json` | 人格预设、模型参数、窗口位置、气泡间隔等 |
| `sessions.json` | 对话历史（明文 JSON，含附件路径元数据） |
| `memory.json` | 长期档案与记忆片段 |

- API Key 优先用 Electron `safeStorage`（Windows 上是 DPAPI）加密后存为 `apiKeyEnc`；不可用时才退回明文，并在设置里提示。
- 没有遥测、没有云端同步；只有你主动聊天/整理记忆时，请求才会发往你配置的 API 地址。
- 附件内容只在你发送该条消息时进入请求；文件本身不会被上传到别处。

## 打包成离线安装包

构建机需要 Node.js 18+；目标机器**不需要 Node、npm 或网络**。

```bash
cd E:\dskPet
npm install
npm run ico      # 由 assets/icon.png 生成多尺寸 icon.ico（已生成可跳过）
npm run dist     # electron-builder --win nsis --x64
```

产物：

- `dist\DskPet-Setup-1.0.1-x64.exe`：离线安装包，约 91 MB，内置 Electron 38 运行库 + 应用全部文件；
  SHA256：`38691B74061B64425DC60355F2A588E2212B1421754ABD2A86DAB35F71450FD7`
- `dist\win-unpacked\`：免安装绿色目录，可直接运行 `绒绒桌宠.exe`；
- 安装过程不会下载任何组件，断网也能完成。

安装：

1. 把安装包拷到目标机器，双击；
2. 选择安装目录（默认 `%LOCALAPPDATA%\Programs\dskpet`，当前用户安装，不需要管理员权限）；
3. 完成后桌面和开始菜单出现「绒绒桌宠」。

静默安装（批量 / 离线部署）：

```bat
DskPet-Setup-1.0.1-x64.exe /S
DskPet-Setup-1.0.1-x64.exe /S /D=E:\DskPet
```

`/D` 必须放在最后，路径不要加引号。

说明：

- 安装包**未做代码签名**，Windows SmartScreen 可能提示“未知发布者”，选择「更多信息 → 仍要运行」即可；这是证书问题，不影响离线安装与运行。
- 卸载在「设置 → 应用」或开始菜单里；默认保留 `%APPDATA%\DskPet\data` 中的对话与记忆。
- **完全离线运行**：应用自身不联网、不自动更新、无遥测。聊天、智能气泡、记忆总结需要你配置的模型接口；没有外网时可用本地 Ollama（`127.0.0.1`），或在设置里关闭「智能气泡」，只用本地台词库。
- 构建时若无法访问 electron-builder 的二进制源，可设置镜像：`ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`。Electron 本体直接复用 `node_modules\electron\dist`，构建阶段也不会重新下载。

已实测：静默安装到默认/自定义目录 → 安装版启动并写入日志 → 卸载后注册表与快捷方式清理干净。

## 常见问题

**会被全屏游戏盖住吗？**
普通窗口、无边框全屏都能压住。独占全屏（Exclusive Fullscreen）由系统/显卡直接接管，任何普通置顶窗都无法覆盖；把游戏改成「无边框窗口」即可。

**聊天报 401 / 404 / 429？**
401：Key 或权限问题；404：Base URL 通常要以 `/v1` 结尾，且模型名存在；429：额度/频率限制。

**记忆不更新？**
需要至少 4 条消息（约 2 轮）才会自动整理，且模型 API 必须可用。可在 🧠 抽屉里点「现在整理一次」手动触发。

**图片发给模型看不懂？**
设置 → 模型 → 打开「视觉输入」，并使用支持多模态的模型（如 GPT-4o、Qwen-VL 等）。

**双击 bat 没反应？**

先看日志 `%APPDATA%\DskPet\logs\app.log`。常见情况：

- 应用已经在后台运行：再次双击会唤醒已有实例（宠物 + 对话窗），不会出现新进程；
- `node_modules` 不完整：在项目目录执行 `npm install` 后重试；
- 被杀毒/安全软件拦截：把项目目录加入信任后重试。

**关闭对话窗后应用还在？**
桌宠是常驻应用，关闭只是隐藏对话窗。退出请用托盘菜单「退出」。

**开机自启在开发模式下指向 electron.exe？**
是的，开发运行与打包运行的可执行路径不同。打包成 exe 后自启会指向应用本身。

**能打包成 exe 吗？**
已经配置好 electron-builder：`npm run dist` 直接生成离线 NSIS 安装包，`npm run pack` 生成免安装目录。详见上文「打包成离线安装包」。

## 已知边界

- 以 Windows 为主要目标调试；Electron 跨平台，但路径识别与交互优先适配 Windows。
- 文本附件 ≤2MB 才会内联；更大的文件只传路径。
- 带空格的本地路径在 Markdown 纯文本里可能只识别到空格前一段，放进反引号或使用 `file://` 链接可完整点击。
- 单实例运行；多宠物/多角色同时出现不在当前范围。
